# FIELD SUPPORT - Trocas e Empréstimos

Painel Kanban desenvolvido em Vue.js para controle operacional de trocas de equipamentos e empréstimos de periféricos do Time de Suporte Field.

## Objetivo

Centralizar a visualização das movimentações realizadas pelo time de suporte, permitindo acompanhar rapidamente:

- Trocas Pendentes
- Trocas Agendadas
- Trocas Concluídas
- Periféricos Emprestados
- Periféricos Devolvidos

O painel foi concebido para exibição em televisões corporativas e ambientes operacionais.
